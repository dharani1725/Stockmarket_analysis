# 📈 Stock Market Analysis Dashboard

A responsive Stock Market Analysis Dashboard built using **HTML, CSS, JavaScript, Chart.js, and REST APIs**. This project allows users to view stock performance over different time periods, compare stock statistics, and read company summaries.

---

## 🚀 Features

- 📊 Interactive stock price chart using Chart.js
- 📈 View stock performance over:
  - 1 Month
  - 3 Months
  - 1 Year
  - 5 Years
- 📋 Display all available stocks dynamically
- 💰 Show Book Value and Profit Percentage
- 🖱️ Click on any stock to update the chart instantly
- 📝 Display company summary for the selected stock
- 🔄 Fetch live data using REST APIs with Async/Await
- 📱 Responsive and clean user interface

## 🎯 Functionalities

- Fetch stock statistics dynamically
- Generate stock cards dynamically
- Load stock chart on selection
- Switch between different time durations
- Display company summary
